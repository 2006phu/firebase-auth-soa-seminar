4. CÁC LỆNH & ĐOẠN MÃ DEMO CI/CD GITHUB ACTIONS (3 TÌNH HUỐNG)
================================================================================

### 4.1. TÌNH HUỐNG 1: Happy Path (Triển khai thành công):
- Vị trí sửa: File `frontend/src/components/Login.jsx` (thẻ <h2>)
- Đoạn text thay thế:
Đăng nhập vào tài khoản (TDTU LIVE DEMO 🚀)

- Lệnh Git nếu commit từ máy:
git commit -am "test: verify automated CI/CD pipeline deployment"
git push origin main

### 4.2. TÌNH HUỐNG 2: Runtime Error ("Build tích xanh nhưng Web trắng bóc"):
- Vị trí sửa: File `frontend/src/components/Login.jsx` (ngay dưới import)
- Dòng code gây lỗi Runtime:
dhsfkjsndkjfndskj

- Lệnh Git nếu commit từ máy:
git commit -am "test: trigger runtime error"
git push origin main

### 4.3. TÌNH HUỐNG 3: Build-time Error & Fail-Safe ("CI/CD chặn đứng, Web vẫn sống"):
- Vị trí sửa: File `frontend/src/components/Login.jsx` (đầu file)
- Dòng code gây vỡ build compile:
import ThuVienAo from './FileKhongTonTai';

- Lệnh Git nếu commit từ máy:
git commit -am "test: trigger build-time compile error"
git push origin main

- Lệnh Rollback / Reset Git sau khi test xong:
git checkout frontend/src/components/Login.jsx
git commit -am "fix: restore clean login page"
git push origin main

5. CÁC LỆNH THIẾT LẬP BAN ĐẦU & CÀI ĐẶT THƯ VIỆN (SETUP REFERENCE)
================================================================================

--- [CÀI ĐẶT FRONTEND]:
cd frontend
npm install
npm run dev
npm run build

--- [CÀI ĐẶT FASTAPI]:
cd backend-fastapi
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

--- [CÀI ĐẶT SPRING BOOT FIREBASE]:
cd backend-springboot
.\mvnw.cmd clean compile
.\mvnw.cmd spring-boot:run

--- [CÀI ĐẶT BACKEND QUÂN OAUTH2]:
cd backend-quan-oauth2
.\mvnw.cmd clean compile
.\mvnw.cmd spring-boot:run

--- [CÀI ĐẶT NODEJS EXPRESS]:
cd backend-nodejs
npm install
npm run dev

--- [CÀI ĐẶT FIREBASE CLI & HOSTING]:
npm install -g firebase-tools
firebase login
firebase init hosting
firebase deploy --only hosting
